# LightPlayer

Мінімалістичний музичний плеєр для Android 10+ (target 15).
Бере треки з `/storage/emulated/0/Music/` (разом з підпапками).

## Збірка
1. Залити проєкт у GitHub-репозиторій (гілка `main`).
2. Actions → "Build APK" запускається сам (або вручну: Run workflow).
3. Готовий `app-debug.apk` лежить в Artifacts запуску.
