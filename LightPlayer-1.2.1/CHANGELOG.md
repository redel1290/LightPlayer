# Список версій

## 1.2 (versionCode 3)
- Плеєр запам'ятовує останній трек, позицію, shuffle і repeat.
- Після повного закриття трек відновлюється на паузі, без автозапуску.
- Якщо треку нема або файл видалено, нічого не вибрано.

## 1.1 (versionCode 2)
- Виправлено лаги прокручування списку: позиція слайдера більше не перемальовує весь список, `Track` стабільний, обкладинки вантажаться у 2 потоках.
- Збірка перейшла з debug на release (R8): APK ~3 МБ замість ~28 МБ, підписаний debug-ключем.

## 1.0 (versionCode 1)
- Перша збірка: список треків з /Music/ (з підпапками), пошук.
- Відтворення у фоні через foreground-сервіс (Media3), сповіщення з керуванням.
- Перемотка, наступний/попередній, shuffle, repeat, обкладинки.
- Кнопка 🔋 для виключення з економії батареї.
- minSdk 29, targetSdk 35.
